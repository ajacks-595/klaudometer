Klaudometer now keeps Claude Code's login renewed, so the meters keep working when you use the Claude desktop app rather than the `claude` command.

## What's fixed

- **Login renewal:** Claude Code's login lasts about 8 hours, and only Claude Code renews it. If you mostly used the Claude desktop app, nothing renewed it and the meters stopped until you next ran `claude`. Now, a few minutes before it runs out, Klaudometer runs `claude doctor`, which makes Claude Code renew it. That makes no model request, so it doesn't count towards your usage. Klaudometer still never renews the login itself.
- **Sign In to Claude Code…:** however often it's renewed, Claude Code's sign-in ends about a month after you sign in. Klaudometer now says so and offers **Sign In to Claude Code…**, which opens `claude auth login` in a terminal. The numbers come back within 15 seconds of you finishing. It's on the widget's card and right-click menu, in the Linux tray menu, and in the macOS and Windows app's menu and card.
- **Clearer messages:** "Signed out of Claude Code" replaces "Login expired. Open Claude Code to refresh it.", which didn't help if you use the desktop app.

## Install or update

Klaudometer uses Claude Code's login on the same computer, so install Claude Code and run `claude auth login` in a terminal first. Signing in to the Claude desktop app doesn't sign in the `claude` command.

- **macOS 11 or later** (Apple silicon or Intel): quit Klaudometer if it's running, download `Klaudometer_1.1.1_universal.dmg`, open it and drag Klaudometer into Applications, replacing the old copy.
- **Windows 10 or 11:** quit Klaudometer if it's running, then download `Klaudometer_1.1.1_x64-setup.exe`, which installs just for you, or `Klaudometer_1.1.1_x64_en-US.msi`, which installs for everyone on the PC. To update, use the same kind you installed 1.1.0 with, and it replaces it.
- **Plasma 6 widget:** for a first install, download `klaudometer-1.1.1.plasmoid`, then right-click the desktop and choose **Add or Manage Widgets › Get New › Install Widget From Local File…**. To update, run `kpackagetool6 -t Plasma/Applet -u klaudometer-1.1.1.plasmoid`, or `./install.sh` from the source, then log out and back in so widgets already on screen pick it up.
- **Linux tray icon:** download the source, then run `tray/install.sh`.

`SHA256SUMS.txt` lists every download's checksum. The macOS and Windows builds still aren't signed, so expect the same first-run warnings as 1.1.0.
