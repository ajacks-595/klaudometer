Klaudometer now runs on **macOS and Windows**, in the menu bar or the system tray.

## What's new

- **macOS and Windows app:**
  - **Icon:** the usage rings in the menu bar or tray. On a Mac, the percentages appear beside it.
  - **Card:** the same rings as the Plasma widget, with how much is left, reset times and pace.
  - **Menu:** each meter's details.
  - **Notifications:** the same alerts as on Linux.
- **Settings window:**
  - which meters to show, themes, colours and levels;
  - notifications and start at login;
  - Claude API spend, with your Admin API key saved in the Keychain or Windows Credential Manager.

The Plasma widget and the Linux tray icon are unchanged apart from the version number.

## Install

Klaudometer uses Claude Code's login on the same computer, so install Claude Code and log in first.

- **macOS 11 or later** (Apple silicon or Intel): download `Klaudometer_1.1.0_universal.dmg`, open it and drag Klaudometer into Applications.
- **Windows 10 or 11:** download `Klaudometer_1.1.0_x64-setup.exe`, which installs just for you, or `Klaudometer_1.1.0_x64_en-US.msi`, which installs for everyone on the PC.
- **Plasma 6 widget:** download `klaudometer-1.1.0.plasmoid`, then right-click the desktop and choose **Add or Manage Widgets › Get New › Install Widget From Local File…**.
- **Linux tray icon:** download the source, then run `tray/install.sh`.

`SHA256SUMS.txt` lists every download's checksum.

### The macOS and Windows builds aren't signed yet

- **macOS** says Klaudometer can't be opened the first time. Go to **System Settings › Privacy & Security** and choose **Open Anyway**.
- **Windows** SmartScreen may warn about an unknown publisher. Choose **More info › Run anyway**.
- **Windows 11** puts new tray icons behind the **^** by the clock. Drag Klaudometer's icon onto the taskbar to keep it in view.

## Before you use it

Klaudometer is unofficial and not affiliated with Anthropic. It reads your own Claude Code login and sends it only to `api.anthropic.com`, and it relies on an undocumented endpoint that could change. See the README's Disclaimer and Known limitations sections.

The macOS and Windows app has been tested on GitHub's Mac and Windows build machines, against a stand-in for Anthropic's API. It hasn't yet been tried with a real account on a real Mac or PC.
